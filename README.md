# TERMA

Сайт термального комплекса в горах. Одна страница: экран героя и семь блоков.

Контекст проекта, дизайн-система и законы — в [CLAUDE.md](./CLAUDE.md).

```bash
npm install
npm run assets   # печёт слои пара, конденсат и сабсеты шрифтов (нужен python3 + Pillow, numpy, fonttools)
npm run dev      # http://localhost:3000/termaa/
npm run build    # статический экспорт в out/
```

Выдача: https://kirill-design367.github.io/termaa/ · витрина шрифтов: `/termaa/fonts/`
